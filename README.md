# カンペカメラ

カンペ(原稿)を読みながら動画を撮影できる、スマホ向けWebアプリです。インストール不要で、ブラウザで開くだけで使えます。

## 機能

- 縦持ちなら縦長(720×1280)、横持ちなら横長(1280×720)で録画(1080pも選択可)
- 映像と音声(マイク)を同時に録画
- 背景切り替え:なし / ぼかし / 単色(白など) / 好きな画像
- カンペは半透明で、後ろの映像が透けて見える(濃さ・文字サイズ・表示エリアの高さを調整可)
- カンペの流れる速さを調整可(録画中も「−」「＋」で変更可)。指でスクロールして位置合わせも可
- カンペの編集・貼り付け・コピー(端末内に自動保存)
- 3秒カウントダウン、前/背面カメラ切替、録画中は画面スリープを防止
- 撮影した動画は「保存 / 共有」(iPhoneは「ビデオを保存」で写真アプリへ)または「ダウンロード」で保存

## 使い方(公開)

カメラを使うため **HTTPS** で開く必要があります。GitHub Pages で公開するのが簡単です。

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を「Deploy from a branch」にし、このブランチと `/ (root)` を選んで Save
3. 表示されたURL(`https://<ユーザー名>.github.io/jobhunting_camera/`)をスマホで開く
4. 「共有 → ホーム画面に追加」でアプリのように使えます

## ファイル構成

- `index.html` 画面
- `style.css` デザイン
- `app.js` カメラ・合成・録画・カンペ制御
- 背景処理には MediaPipe(Selfie Segmentation)を CDN から読み込みます(背景をオンにしたときのみ)

## 注意

- 録画ファイルの形式はブラウザによって MP4 または WebM になります(iPhone Safari / 最近のChromeはMP4)。
- 背景処理は端末の性能によってはカクつくことがあります。その場合は画質を720pにしてください。
